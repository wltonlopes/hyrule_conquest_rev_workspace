#General Errors
==================
* At some point, a strange error appeared, saying that it is using an invalid passability class
  called "unrestricted". This does not affect gameplay in any way, it's just an error message. I 
  think it is caused by something in the Lanayru civ.

#Civs
==================
All errors for specific civilizations are listed here, under the civlilization that they belong to.

#Deku
==========
* Because Deku Babas can't move, when you turret them on a Deku Scrub, they break any formations. 
  Individual movement still works, but formations won't move. This error will probably never be fixed.
    
#Wild Zora
==========
* The Wild Zora do not work with any existing AI, though a custom AI for them, called ZolBot, is 
  planned for the future.

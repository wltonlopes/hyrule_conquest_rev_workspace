# Hyrule Conquest: Revival
Adding many factions, features, and maps from the Legend of Zelda series.

*Hyrule Conquest: Revival* is a mod for [*0 A.D. Empires Ascendant*](https://play0ad.com/), adding features, factions, and other stuff from The Legend of Zelda. It currently introduces the following civilizations:
* Deku Kingdom
* Fairies
* Gorons
* Kingdom of Hyrule
* Kokiri
* Labrynna Empire
* Lanayru Province
* Ordona Province
* Stalfos
* Wild Zora

It also adds the following Minor Civilizations:
* Darknuts
* Keaton Cartel
* Lon Lon Ranch
* Gorons of Rolling Ridge
* Tokay
* Order of the Wizzrobe
* Zuna

This repository is created to track all tasks related to the Hyrule Conquest: Revival mod.
